The change

type Base = {
  title: string;
  // A string, or lines: one <p> each, 8 px apart.
  description: string | string[];
  // New: between the description and the buttons.
  children?: ReactNode;
  // New: why the action can’t go ahead, when no
  // field holds it. Small Danger, role="alert".
  error?: string;
  cancelLabel?: string;   // “Close” in a notice
} & (
  | { status?: 'ready' }
  | { status: 'loading'; loadingLabel: string }
  | { status: 'error'; errorTitle: string;
      errorText: string;
      onRetry: () => Promise<unknown> }
);
type Confirm =
  | { notice?: never; confirmLabel: string;
      pending: boolean; pendingLabel: string;
      tone?: 'danger' | 'primary';
      onConfirm: () => void }
  | { notice: true; confirmLabel?: never; … };
type ConfirmDialogProps = Base & Confirm & OpenProps;

A step is a re-render. The caller swaps description, children, confirmLabel and tone; the title stays. Controlled (open), the confirm shows pending and the caller closes it, as today.

While loading or failed there’s no confirm, and focus stays on Cancel. A notice has only the way out, “Close” unless cancelLabel says otherwise.
