Lines, not a paragraph. Each consequence is its own Body line in Muted, 8 px apart, so a line can go when its number is 0 without the rest reading oddly. The numbers come from the API, never estimated; “recipe” and “recipes” follow the number.

Send code is primary, not danger. Pressing it deletes nothing: it only emails a code. The danger button comes in the next step, named for the action, “Delete account”, as docs/design.md’s Dialog row says. Primary is the dialog’s one main action while the page sits under the scrim (see Proposed rule change).

Focus lands on Cancel when it opens, as every alert dialog’s does, so Enter never sends a code by accident. Escape and Cancel close it and give focus back to Delete account.

Checking and Couldn’t check keep the title, so the screen reader names the dialog straight away; the Loading line shows after half a second, as States › Loading says. Try again only fetches the numbers again.

Staff keep the title as asked, and the dialog becomes a notice: its way out reads “Close”, as nothing is being cancelled, and there’s no Send code.
