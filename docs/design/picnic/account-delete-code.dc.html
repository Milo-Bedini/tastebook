One dialog, two steps. The title stays “Delete your account?” throughout, so the question being asked never changes; the description swaps from what goes and stays to where the code went. The address is bold and wraps anywhere, as on sign-in.

Send a new code sits under the field, a secondary button on its own line, rather than a third button in the row: at 390 px three buttons would wrap and push Delete account away from Cancel. The spec lists it in the button row; this places it with the field it refills.

The field’s rules are sign-in’s: label “Code”, the number keyboard, one-time-code autofill, at most 6 characters; errors replace nothing, sit in the field’s own line and go when Delete account is pressed again.

A thrown request is a toast (dock colours, at the foot), as the spec says, so the code stays in the field and pressing again is the retry. “Couldn’t send the code. Check your connection and try again.” is the same toast for either send.
