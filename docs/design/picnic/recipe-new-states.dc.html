Errors sit in the field’s own line, as on the account page: the help line gives way to the message, in Danger with its icon, and the field takes Danger’s border. Every check’s message says how to fix it with an example (Voice). A 400 naming a field puts its message under that field the same way.

Servings of 0 is refused with the spec’s “Enter a number, like 4.”, since the check is “a whole number from 1”; a blank number field is never an error, as every detail but the title is optional.

A refusal that names no field (the servings-or-yield rule, normally caught first by the form) is a danger Banner titled “Couldn’t save the recipe” with Tastebook’s message under it, right above Save, and focus moves to it (the ring shows where). It goes when Save is pressed again.

A failed request is a toast, not a Banner, as on the account page: the form is still open with everything typed, so Save recipe again is the retry. On success there’s no toast: the recipe’s own page opening is the confirmation.

Signed out, the page sends you to sign-in and back (/sign-in?next=%2Frecipes%2Fnew), so there’s nothing to draw; the sign-in boards already cover that page. A 403 on Save does the same once the session says you’re signed out.
