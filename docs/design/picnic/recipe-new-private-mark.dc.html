The transparent border is drawn in CanvasText; the lock follows the text.

One component, no props, for now. <PrivateMark /> renders the lock and “Private” as a span; the page decides where it goes and shows it only when recipe.visibility === 'private'. On a card its text joins the link’s description with the meta, so a screen reader hears “Grandma’s curry, link, Private, 40 min · Easy · Indian”.

What it should grow into: when a second mark arrives (a copy, TAS-126, or a recipe shared by link, TAS-128), make it RecipeMark with a kind, each kind a Lucide icon and one word in this same shape. Public recipes stay unmarked: public is the default and needs no label.

Stories: on Ground, on a card, under a title, at 200% text and under forced colours. It has no hover, pressed, focus or disabled state, as it isn’t interactive.
