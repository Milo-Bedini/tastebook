One group: everything only the author can do stays together, and the link is right where it was turned on, so there’s no second place to look. Two switches read as two separate answers to “who can see this?”. The intro grows by about 230 px while the link is on.

Only the author sees it, beside Public (the same can_publish-style flag, say can_share). Another member, another household and someone signed out see the page without it: see the states board.

Switch gains a help line (its own board): Small Muted under the row, tied to it with aria-describedby, saying what turning it on does before you do it. The link field is the household page’s invite-link field as it is: Label, a read-only Input that selects the whole address on focus, a help line.

Copy link is secondary, so the screen still has no peach button competing with cooking. A private recipe with gaps can be shared: the link shows it as it is, while Public stays disabled with its reason.
