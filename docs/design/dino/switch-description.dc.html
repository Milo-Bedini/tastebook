Why on Switch, not beside it: the help belongs to the control, so a screen reader hears it with “Share by link, switch, off”. Segmented control already has the same help line; this follows it (design.md, Segmented control). Hover, pressed and focus stay on the row only, so the help line isn’t part of the target.

Disabled shows its reason and not the help, so there’s one line under the row at a time; the help comes back once it’s enabled. Under forced colours the line is CanvasText like any text. Its stories gain with-description and with-description-is-on.
