type Base = {
  title: string;
  description: string;
  confirmLabel: string;
  cancelLabel?: string;
  pending: boolean;
  pendingLabel: string;      // "Making public…"
  tone?: 'danger' | 'primary'; // default 'danger'
  onConfirm: () => void;
};
type ConfirmDialogProps = Base & (
  | { trigger: ReactElement; open?: never; onOpenChange?: never }
  | { trigger?: never; open: boolean;
      onOpenChange: (open: boolean) => void }
);

With a trigger, pending shows on the trigger, as today. Controlled, there’s no trigger on screen to show it, so the confirm does, and pressing it doesn’t close the dialog: the caller closes it when the answer comes. Cancel and Escape still close it.

Primary is the peach button with its press shadow: while the dialog is open it is the screen’s one main action. Use it only where the action can be undone; anything final stays danger.
